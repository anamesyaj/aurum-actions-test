# Upload PDFs here

Public-repository warning: anything committed here is publicly readable,
including sheet-music PDFs. Deleting a PDF from the latest branch does not
remove it from previous commits or Git history.

On Android, open this folder on github.com. Tap Add file → Upload files,
select your musical score PDF and commit it to the main branch. Uploading
automatically starts the ScoreLight PDF → MusicXML workflow.

Then visit Actions → ScoreLight · PDF to MusicXML → newest run. When the
conversion finishes, download its scorelight-musicxml ZIP artifact, unzip
it in Android Files and import the MusicXML into PuddleLoom ScoreLight.

Only publish PDFs that you have the right to share publicly.
Limit: 15 MB per PDF; up to 4 new PDFs per commit.
